# むちねこ

食べるほど、強くなる。

Раннер про кота на крышах. Чем больше кот ест, тем он больше и сильнее: проламывает ящики, продавливает весы, выше отскакивает от футонов и захватывает больше еды. А вес — ещё и топливо для прыжка в воздухе.

## Управление

| Действие | Тач | Клавиатура |
| --- | --- | --- |
| Прыжок (удержание — выше) | тап | Space / ↑ / W |
| ぴょん: прыжок в воздухе (−8% веса) | тап в воздухе | то же |
| Быстрое падение | свайп вниз | ↓ / S |
| Пауза | кнопка ❙❙ | Esc / P |
| Рестарт | — | R |
| Звук | — | M |

## Механика

- Вес 0–100 % растит кота (хитбокс до ×1,5) и немного снижает прыжок.
- カリカリ: +1 очко, +2,5 %. ねこ缶: +5 очков, +12 %. ねこじゃらし: +2 очка, −15 %. 鈴 — колокольчики для третьей звезды.
- ぴょん: один прыжок в воздухе за полёт, стоит 8 % веса. Еда — топливо.
- 段ボール: тяжёлый кот (вес ≥ порога) проламывает ящик (+3 очка и то, что внутри), лёгкий должен перепрыгнуть.
- ふとん подбрасывает тем выше, чем кот тяжелее. 体重計 опускает мост тяжёлому; лёгкий перелетает щель через ぴょん.
- 電線 держит только лёгкого. Под проводом всегда есть нижняя дорога для тяжёлых, с консервами и футоном наверх.
- 提灯 — чекпоинты: после падения забег продолжается с последнего фонаря.
- Звёзды: ★ финиш, ★ очки ≥ цели, ★ все колокольчики.

8 уровней (`src/levels/`), по механике на уровень, затем ночной забег и финальная башня. Бесконечный режим открывается после 4-го уровня.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов и сборка в dist/
npm run verify   # бот-решатель проверяет, что каждый уровень проходим на 3★
```

Симуляция (`src/sim/`) детерминирована и не зависит от Phaser, поэтому `tools/solver.ts` (beam search по действиям) гоняет те же уровни в Node и пишет трассы в `tools/traces.json`.

Dev-параметры URL: `?stage=N` или `?stage=endless` — сразу в уровень, `?replay` — проигрывать трассу бота, `?fast=N` — ускорение, `?rs=1` — рендер в 1× (быстрее в headless).

Стек: Phaser 3, TypeScript и Vite. Графика векторная (SVG в коде, `src/art/`), звук синтезируется через WebAudio (`src/systems/Sound.ts`).

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages при пуше в `main`.
