# むちねこ

食べたい。でも、飛べなくなる。

Раннер про кота на крышах. Еда даёт очки и вес, а вес решает, какие препятствия кот пройдёт. Каждый уровень — головоломка: сколько съесть и когда сбросить вес, чтобы прийти к финишу с нужным счётом и в нужном весе.

## Управление

| Действие | Тач | Клавиатура |
| --- | --- | --- |
| Прыжок (удержание — выше) | тап | Space / ↑ / W |
| Быстрое падение | свайп вниз | ↓ / S |
| Пауза | кнопка ❙❙ | Esc / P |
| Рестарт | — | R |
| Звук | — | M |

## Механика

- Вес 0–100 % меняет силу прыжка и гравитацию. Скорость бега постоянна.
- カリカリ: +1 очко, +2 % веса. ねこ缶: +5 очков, +12 %. ねこじゃらし: −20 %. На бегу вес сгорает (0,6 %/с).
- 電線 (провод) держит только кота не тяжелее порога, иначе рвётся.
- ふとん (футон) подбрасывает тем выше, чем кот тяжелее; на высокую стену нужен минимальный вес.
- ビル風 (ветер между домами) поднимает только лёгкого кота.
- 体重計 (весы) опускают мост, если кот достаточно тяжёлый.
- Звёзды: ★ финиш, ★ очки ≥ цели, ★ вес на финише в заданной полосе.

8 уровней (`src/levels/`) по одному на механику, плюс развилка, ночной забег и финальная башня. Бесконечный режим открывается после 4-го уровня.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов и сборка в dist/
npm run verify   # бот-решатель проверяет, что каждый уровень проходим на 3★
```

Симуляция (`src/sim/`) детерминирована и не зависит от Phaser, поэтому `tools/solver.ts` (beam search по действиям) гоняет те же уровни в Node и пишет трассы в `tools/traces.json`.

Dev-параметры URL: `?stage=N` или `?stage=endless` — сразу в уровень, `?replay` — проигрывать трассу бота, `?fast=N` — ускорение, `?rs=1` — рендер в 1× (быстрее в headless).

Стек: Phaser 3, TypeScript и Vite. Графика векторная (SVG в коде, `src/art/`), звук синтезируется через WebAudio (`src/systems/Sound.ts`).

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages при пуше в `main`.
