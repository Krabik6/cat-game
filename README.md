# むちねこ

食べたい。でも、飛べなくなる。

Горизонтальный раннер про кота на крышах: чем больше он ест, тем тяжелее становится и тем хуже прыгает. Задача — добраться до финиша на 600 м и собрать как можно больше корма.

## Управление

| Действие | Тач | Клавиатура |
| --- | --- | --- |
| Прыжок (удержание — выше) | тап | Space / ↑ / W |
| Быстрое падение | свайп вниз | ↓ / S |
| Пауза | кнопка ❙❙ | Esc / P |
| Звук | — | M |

## Механика

- Вес 0–100 % меняет скорость, силу прыжка и гравитацию (`src/config.ts`, блок `WEIGHT`).
- カリカリ: +1 к счёту и немного веса; ねこ缶: +5 к счёту и много веса.
- Вес понемногу сгорает на бегу.
- Промежутки между крышами рассчитаны на кота весом около 55 % и усложняются к финишу. Если кот тяжелее, он может не допрыгнуть.
- Рекорд засчитывается только для забега, дошедшего до финиша.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов и сборка в dist/
```

Стек: Phaser 3, TypeScript и Vite. Вся графика векторная и рисуется в коде (`src/art/`), звук синтезируется через WebAudio (`src/systems/Sound.ts`). Внешних ассетов нет.

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages при пуше в `main`. Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.
